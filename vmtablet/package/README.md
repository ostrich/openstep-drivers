# Packaging VMTablet

This directory builds the installable package for absolute mouse integration.
For the benefits, supported configuration and installation steps, start with
the [user README](README.distribution.txt).

Use `build-on-openstep.sh` with native Developer Tools, then validate and wrap
the package with `distribute.py`. See [build instructions](../../docs/build.md)
and the [installation README](README.distribution.txt).
