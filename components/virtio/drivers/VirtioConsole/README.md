# VirtioConsole

Two bidirectional legacy virtio PCI console ports for OPENSTEP 4.2 Intel.
One port supports the QEMU guest agent and the other an interactive PTY.
The services can be enabled independently.

Build with native Developer Tools using `make`. Keep `../../src` in place.
Install through the combined OpenStepVirtioServices distribution; see its
[README](../../package-services/README.txt) and
[build instructions](../../../../docs/build.md).
